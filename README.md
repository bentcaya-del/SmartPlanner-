# SmartPlanner

Application web de planification de tâches. Tu renseignes tes tâches avec leur durée et leurs propriétés, et SmartPlanner génère automatiquement un planning. Les tâches sont sauvegardées en JSON.

---

## Stack technique

- Frontend : HTML, CSS, JavaScript (Vite)
- Backend : Node.js
- Stockage : JSON

---

## Lancer le projet

### 1. Cloner le repo

```bash
git clone https://github.com/bentcaya-del/SmartPlanner.git
cd SmartPlanner
```

### 2. Lancer le backend

```bash
cd backend
npm install
npm run start
```

### 3. Lancer le frontend

```bash
cd frontend
npm install
npm run dev
```

Ouvre ensuite l'URL affichée dans le terminal (par défaut `http://localhost:5173`).

> Le backend doit être lancé avant le frontend pour que l'application fonctionne correctement.

---

## Fonctionnalités

- Ajout de tâches avec durée et propriétés
- Génération automatique d'un planning
- Sauvegarde des tâches en JSON
